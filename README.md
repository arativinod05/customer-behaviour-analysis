# customer-behaviour-analysis
Customer Shopping Trends Analysis

An end-to-end data analysis project exploring customer shopping behavior to uncover insights that can guide marketing and sales decisions.

What it covers

Data cleaning and exploration in Python (pandas)
SQL queries to answer business questions, such as top-selling categories, spend by age group and gender, and the impact of discounts and subscriptions
An interactive Power BI dashboard visualizing key metrics and customer segments

Tech stack: SQL, Python (pandas, matplotlib/seaborn), Power BI
